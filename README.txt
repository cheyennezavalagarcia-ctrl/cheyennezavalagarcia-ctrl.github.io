# Adopta Patitas 🐾

Página editable para publicar perros y gatos en adopción.

## Archivos
- `index.html` — estructura de la página.
- `style.css` — diseño y colores.
- `script.js` — buscador, filtros, fichas, formulario y QR.

## Cómo usarla
1. Abre `index.html` en tu navegador.
2. En "Publicar una mascota" puedes agregar nombre, tipo, edad, sexo, zona, contacto, foto y descripción.
3. Las mascotas que agregues se guardan en el navegador mediante `localStorage`.
4. Para que otras personas puedan entrar desde sus celulares, sube los tres archivos a un servicio de hosting estático (por ejemplo GitHub Pages).
5. Cuando tengas la URL pública, pégala en la sección "Genera tu código QR" y pulsa "Generar QR".

## Importante
Las fotos que agregues mediante el formulario se guardan en el navegador de quien las publica. Para un sitio público real donde varias personas puedan publicar desde distintos teléfonos, necesitarás una base de datos/servidor (por ejemplo Supabase o Firebase).

Puedes cambiar textos, colores, nombre del sitio, contactos y mascotas directamente en los archivos.
